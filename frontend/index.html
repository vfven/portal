Guía: Construcción de manifiestos con Kustomize

▼

Kustomize permite personalizar manifiestos de Kubernetes sin templates. Sigue esta estructura estándar.

1 Estructura de directorios
📁 app-mi-servicio/
├── 📁 base/
│ ├── deployment.yaml
│ ├── service.yaml
│ ├── configmap.yaml
│ └── kustomization.yaml
└── 📁 overlays/
├── 📁 dev/
│ ├── kustomization.yaml
│ └── patch-replicas.yaml
├── 📁 qa/
└── 📁 prod/
2 base/kustomization.yaml
apiVersion: kustomize.config.k8s.io/v1beta1 kind: Kustomization resources: - deployment.yaml - service.yaml - configmap.yaml commonLabels: app: mi-servicio managed-by: kustomize
3 Overlay dev (overlays/dev/kustomization.yaml)
apiVersion: kustomize.config.k8s.io/v1beta1 kind: Kustomization resources: - ../../base namespace: dev patches: - target: kind: Deployment name: mi-servicio patch: |- - op: replace path: /spec/replicas value: 1
4 Comandos útiles
# Ver resultado kustomize build overlays/dev # Aplicar kubectl apply -k overlays/dev/ # Diferencia entre entornos kustomize build overlays/dev | diff - <(kustomize build overlays/prod)
Recomendación Banco BASE: Usa esta estructura para todas las aplicaciones. Los overlays por ambiente permiten mantener la base limpia.

Despliegue On-Prem

Pipeline automatizado para infraestructura local. Integración completa con Jira Service Desk, Jenkins y Kubernetes.

Responsabilidades

Solicitante (Developer)

Completa el ticket en Jira Service Desk con repositorio, rama y ambiente destino.

Aprobador (Tech Lead)

Revisa la solicitud en Jira. Aprueba o rechaza según criterios de calidad y seguridad.

DevOps Platform

Mantiene el pipeline de Jenkins, el clúster Kubernetes y la integración con Jira.

Detalle técnico

Variables que recibe Jenkins desde Jira (Webhook JSON):

SUMMARY=Despliegue en QA ENVIRONMENT=QA APPLICATION=App X REPOSITORY=repo-app-x REQUESTER=usuario@empresa.com REQUEST_KEY=SDS-1234

Pipeline: Checkout → Build → Test → Security Scan → Deploy to K8s → Health Check

Notificación: Jenkins envía correo al solicitante con el resultado del despliegue.
